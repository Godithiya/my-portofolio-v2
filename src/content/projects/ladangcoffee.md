Ekosistem empat aplikasi untuk operasional kafe: public marketing site (Astro), reservasi dan self-service order pelanggan (SvelteKit SPA) dengan tiga mode QR (meja, zone, event), dashboard admin dan POS internal untuk sembilan role staf, serta satu backend API (Elysia + Bun) sebagai sumber kebenaran data. Real-time update via native WebSocket, pembayaran online terintegrasi Midtrans, dan signature HMAC untuk anti-tampering order. Di sisi DevOps, menangani deployment dan infrastruktur seluruh domain aplikasi.
